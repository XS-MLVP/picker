# Contributing / 参与贡献

[English development guide](doc/en/development/contributing.md) | [中文开发指南](doc/zh/development/contributing.md)

Use a topic branch and submit a PR targeting master. Explain the problem, resulting behavior and tests run; choose exactly one release:patch/minor/major label. Update both language references when changing an interface. Start with the [architecture](doc/en/explanation/architecture.md) and [documentation workflow](doc/en/development/documentation.md).

在独立分支修改并提交到 master 的 PR，说明问题、改后行为与实际测试，选择且仅选择一个 release:patch/minor/major 标签。接口改动同步中英文文档。先看[架构](doc/zh/explanation/architecture.md)与[文档工作流](doc/zh/development/documentation.md)。

Before reporting an issue, search [existing issues](https://github.com/XS-MLVP/picker/issues) and include a minimal reproducer with tool versions. 提交问题前先搜索已有记录，附最小复现和工具版本。Community QQ / 社区 QQ：600480230。
